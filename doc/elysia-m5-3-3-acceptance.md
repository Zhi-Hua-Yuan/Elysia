# Elysia M5.3.3 单人对话接入与确定性反馈验收

更新日期：2026-08-14

当前状态：**实现与自动化验收通过**。

## 固定范围

本里程碑将 M5.3.1 的显式命令解析和 M5.3.2 的业务服务接入单人对话，在 ASR
最终文本之后、Agent 调用之前执行，并通过现有字幕、TTS、表情和打断链路提供
确定性反馈。

- 不调用额外 LLM、Embedding、网络服务或工具；
- 不从普通聊天、图片或历史中隐式提取记忆；
- 不开放群聊、代理模式或其他 Agent 的持久记忆命令；
- 不实现 M5.4 前端管理请求和管理界面；
- 不改变 M5.2 的动态上下文注入方式；
- 不修改最终 Live2D 或角色声音资产边界。

## 实现结果

### 连接级命令控制

- [x] 新增 `ExplicitMemoryCommandController`，串联确定性解析、资格校验和业务服务；
- [x] 控制器按 `ServiceContext` 实例创建，持有当前连接独立的清空确认状态；
- [x] 共享 `PersistentMemoryService` 不保存连接状态，不会跨客户端共享确认；
- [x] 普通聊天返回未处理哨兵并继续既有 Agent 流程；
- [x] 新的普通输入、其他命令、配置切换和连接关闭会清除旧确认；
- [x] 主动说话与 `skip_memory` 输入不进入命令解析；
- [x] 功能关闭、`explicit_capture` 关闭、代理模式和非 `basic_memory_agent`
  均使用稳定 `memory_disabled` 结果拒绝执行；
- [x] 作用域非法和存储不可用分别返回 `invalid_scope` 与 `storage_failure`；
- [x] 意外异常只记录异常类型，不记录命令原文或记忆正文。

### 清空确认

- [x] 非空记忆清空需要当前连接内的二次确认；
- [x] 确认状态只保存作用域、expected revision 和 UTC 过期时间，不保存正文；
- [x] 默认确认有效期为 60 秒；
- [x] 确认是一次性的，并发双确认最多只有一个可以执行；
- [x] 无待确认、确认过期和主动取消均返回稳定结果；
- [x] 确认后 revision 变化会拒绝清空，避免删除确认之后的新内容；
- [x] 空记忆清空为幂等成功，无需创建待确认状态；
- [x] 清空成功继续使用 M5.3.2 replacement 备份，已删除正文不能从备份恢复。

### 结果协议与固定反馈

- [x] 每个已识别命令先发送 `memory-operation-result`；
- [x] 事件只包含 command、status、action、稳定原因码、changed、item count、
  revision 和可选 memory id；
- [x] 事件不包含命令原文、保存值、删除目标、查询条目、文件路径或异常正文；
- [x] 成功、幂等、拒绝、歧义、冲突和失败均由本地固定映射生成反馈；
- [x] 只有真实成功结果可以使用“我记住了”等成功文案；
- [x] 查询按业务层确定性顺序朗读，最多五条并受 320 字符预算约束；
- [x] 显式命令跳过 Agent，避免 LLM 改写或误报操作结果；
- [x] 固定反馈不经过翻译器，避免增加网络请求或改变确定性文案；
- [x] 固定反馈复用现有字幕、TTS 和音频消息顺序；
- [x] 表情使用模型无关的 key，当前模型缺少对应表情时降级为空动作。

### 打断与历史

- [x] 可能写入的业务调用使用 cancellation-safe 等待；
- [x] 打断反馈播报不会回滚已经完成的本地写入；
- [x] 记忆命令回合不会调用 Agent，也不会把打断反馈写入 Agent 短期上下文；
- [x] 命令和固定反馈继续沿用现有聊天历史写入规则；
- [x] 文本输入和语音输入都只使用 `process_user_input` 返回的最终文本解析。

## 退出结论

M5.3.3 的退出条件已经满足：显式记忆命令在单人文本和语音输入中均根据真实
存储结果反馈；普通聊天保持既有 Agent 主链路；任何拒绝、歧义、冲突、过期或
存储失败场景都不会声称已经记住。

下一步进入 M5.3.4：完成 M5.3 阶段级回归和人工语音验收，重点检查真实 ASR
表达、TTS 播放与打断、跨会话召回、配置切换和故障降级，不提前实现 M5.4
管理界面。
