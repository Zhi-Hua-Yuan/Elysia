# Elysia M5.3.1 命令与策略契约验收

更新日期：2026-08-13

当前状态：**实现与自动化验收通过**。

## 固定范围

本里程碑只固化显式记忆命令和内容策略的纯本地契约，不读写记忆文件，不接入
`ServiceContext`、单人对话、Agent 或 WebSocket，也不提前实现 M5.3.2—M5.4。

- 不调用 LLM、网络、文件系统或外部服务；
- 不从普通聊天中隐式提取记忆；
- 不改变 M5.2 的 Store、Service、上下文缓存或 Prompt 注入；
- 不创建或修改 `memory_data/`；
- 不开放群聊、代理模式或多用户记忆。

## 实现结果

- [x] 新增保存、查询、删除、清空、确认清空和取消清空的命令类型；
- [x] 新增 `recognized`、`not_command`、`invalid` 三态解析结果；
- [x] 命令模型通过字段互斥约束阻止不完整或混合负载；
- [x] 新增不携带记忆正文的清空确认模型，绑定作用域、revision 和 UTC 过期时间；
- [x] 补充 `confirmation_required`、`confirmation_expired` 和
  `confirmation_not_pending` 稳定原因码；
- [x] 新增 NFKC、空白、末尾标点和匹配文本规范化纯函数；
- [x] 采用预编译、整句锚定规则解析中文显式命令；
- [x] 按确认、取消、清空、查询、删除、称呼、保存和否定的优先级处理；
- [x] 普通聊天、引用语句和一般“记得吗”问题保持 `not_command`；
- [x] 空值、空删除目标、否定、冲突命令、控制字符和超长显式命令安全拒绝；

- [x] 策略结果在拒绝时只返回稳定原因码，不回传命中内容；
- [x] 新契约已通过 `open_llm_vtuber.memory` 公共入口导出。
