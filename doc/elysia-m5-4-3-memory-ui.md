## 1. 范围

本阶段只在现有设置抽屉中增加“记忆”页，复用已有 `/client-ws` 连接和
M5.4.2 WebSocket v1 协议，不增加 HTTP API、独立窗口、自动记忆抽取或
Live2D/声音资产逻辑。

已实现：

- 持久记忆总开关、本地明文未加密提示、条数与容量；
- 按称呼、偏好、重要事实三类展示；
- 添加、编辑、删除单条记忆，以及二次确认后清空全部；
- 后端不可用、权限拒绝、功能关闭、存储失败、协议错误、revision/setting
  冲突和超时的独立提示；
- 中英文界面文案；
- 面板关闭、角色切换、断线和重连时的 generation 与定时器清理；
- 修改操作单在途、后端 revision 驱动和修改后强制重新读取。

## 2. 使用方法

1. 正常启动后端和 Web/Electron 前端，并确认左上角 WebSocket 状态为已连接。
2. 打开“设置”，选择“记忆”页。
3. 阅读本地明文提示；不要保存密码、令牌、证件、银行卡或操作指令。
4. 需要在对话中使用记忆时打开总开关。关闭总开关只停止对话读取、写入和
   Prompt 注入，不删除已有数据。
5. 添加或编辑时选择类别并填写正文。所有正文按纯文本显示。
6. 删除单条记忆可直接执行；清空全部必须在界面内再次确认。

管理页的每次写操作都使用当前列表的 `revision`。写操作期间以及写后重新读取
完成前，其他写按钮保持禁用。界面不会用本地内容乐观覆盖服务器结果。

## 3. 超时与冲突语义

- 读取超时：当前读取失败，可手动刷新。
- 修改超时：结果为“未知”，不能假定成功或失败。前端会立即重新请求状态和
  列表，用户必须核对新列表后再操作。
- `revision_conflict`：其他操作已更新列表，前端重新读取后要求用户重新确认。
- `setting_conflict`：总开关已被其他连接改变，前端重新读取真实状态。
- 旧 `request_id`、旧 generation 或响应 operation 不匹配时不会更新当前数据。

## 4. 常见故障

| 界面状态 | 含义 | 处理 |
| --- | --- | --- |
| 后端连接不可用 | WebSocket 未连接或已断开 | 确认后端端口和 WebSocket URL，重连后面板会自动刷新 |
| 只允许本机连接 | 管理请求不是来自回环地址 | 在运行后端的同一台机器使用管理页 |
| 代理/群聊不支持 | 当前连接模式不具备管理权限 | 切换到本机单人会话 |
| 当前 Agent 不支持 | 不是 `basic_memory_agent` | 切换到支持轻量记忆的角色配置 |
| 本地存储不可用 | 目录不可读写或数据文件异常 | 检查 `memory_data/` 权限和后端日志中的脱敏原因 |
| 协议不兼容 | 前后端不是同一管理协议版本 | 使用匹配的主仓库后端与前端 build 提交 |
| 容量已满 | 达到 `max_items` | 删除不需要的条目后再添加 |

前端日志不得输出 `memory-list`、添加或编辑负载。通用 WebSocket 发送失败日志也
只记录连接状态，不打印消息对象。
