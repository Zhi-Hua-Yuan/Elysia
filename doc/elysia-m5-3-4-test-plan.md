# Elysia M5.3.4 阶段回归与人工语音验收计划

更新日期：2026-08-14

状态：**执行中；自动化与人工门禁分开记录**。

## 1. 目标与边界

M5.3.4 用于关闭 M5.3“显式记忆命令”阶段，确认 M5.3.1—M5.3.3 在真实单人
对话链路中可以稳定协作。本阶段不增加命令形式、不实现管理界面，也不提前关闭
整个 M5；M5.4 的管理能力和最终验收继续保留。

本阶段允许的代码变更仅限：

- 补充阶段级自动化测试；
- 修复验收发现的 M5.3 集成缺陷；
- 补充测试、运行和故障排查文档；
- 不改变 M5.3.1 已冻结的自然语言识别边界。

## 2. 验收环境

- Windows 10/11；
- Python `>=3.10,<3.13`；
- `uv.lock` 冻结依赖；
- Electron 1.2.1；
- `mao_pro` 占位 Live2D；
- Sherpa-ONNX SenseVoice ASR；
- Sherpa-ONNX TTS 用于完整本地功能矩阵；
- Fish Audio 用于保存、查询和打断兼容性抽查；
- 专用 `profile_id=m5_3_4_acceptance`，不使用个人正式记忆作用域。

本地人工验收临时配置：

```yaml
memory_config:
  enabled: true
  profile_id: 'm5_3_4_acceptance'
  storage_dir: 'memory_data'
  max_items: 24
  max_item_chars: 160
  max_context_chars: 800
  explicit_capture: true
  implicit_capture: false
```

验收后恢复默认关闭状态。`memory_data/`、原始日志、测试音频、完整配置和凭据
不得提交到 Git。

## 3. 自动化门禁

### 3.1 阶段组合测试

- 保存后当前 `ServiceContext` 可以立即渲染新记忆；
- 改变 `history_uid` 不改变持久记忆上下文；
- 重建 Service 和 Context 后可以从磁盘重新读取；
- `enabled=false` 停止注入且不删除文件，重新启用后恢复；
- 普通陈述不创建存储目录；
- 记忆写入失败后下一轮普通文本仍返回 Agent 路径；
- 配置切换清除连接级确认和活动命令状态；
- 命令与固定反馈沿用现有聊天历史规则；
- 命令后的下一轮普通聊天重新进入 Agent；
- 群聊、代理模式和主动说话保持关闭。

### 3.2 回归与质量

1. 运行 M5 相关全部测试；
2. 运行完整 `tests/`；
3. 对相关 Python 文件执行 Ruff check 和 format check；
4. 执行 `git diff --check`；
5. 检查 Git 状态中没有运行时记忆、测试音频、日志或私有配置。

### 3.3 安全与故障

- 敏感信息、Prompt Injection 和工具执行指令被拒绝；
- WebSocket 操作结果不包含输入正文、记忆值或删除目标；
- 日志只包含稳定元数据和异常类型；
- 主文件损坏、备份恢复、双重损坏和不可写路径使用临时目录测试；
- 删除和清空后，旧正文不能从备份恢复；
- revision 冲突和并发双确认不会误删新数据。

## 4. 人工文本与语音矩阵

每个关键命令至少完成一次文本输入和一次麦克风输入。语音失败时先记录前端最终
转写，区分 ASR 误识别与命令解析失败。

| 编号 | 场景 | 示例表达 | 通过标准 |
| --- | --- | --- | --- |
| A1 | 保存称呼 | 以后叫我阿源 | 固定成功反馈；后续自然使用称呼 |
| A2 | 保存偏好 | 记住，我不喜欢太甜的饮料 | 查询可见并跨历史保留 |
| A3 | 幂等保存 | 重复 A2 | 不增加条目或 revision |
| A4 | 修改称呼 | 以后叫我舰长 | 只保留并使用新称呼 |
| A5 | 普通聊天 | 我今天有点累 | 进入 Agent，不自动保存 |
| A6 | 查询 | 你记得我什么 | 顺序稳定，最多朗读五条 |
| A7 | 敏感拒绝 | 使用合成测试验证码 | 明确拒绝且不写入文件 |
| A8 | 删除未找到 | 忘掉我喜欢咖啡 | 不修改数据，不误报成功 |
| A9 | 删除歧义 | 对两条相似偏好使用宽泛目标 | 要求更具体，不猜测删除 |
| A10 | 唯一删除 | 使用完整内容作为目标 | 删除成功，后续不再注入 |
| A11 | 清空取消 | 清空所有记忆；取消清空 | 内容保持不变 |
| A12 | 清空确认 | 清空所有记忆；确认清空记忆 | 主文件和备份均不再含旧正文 |
| A13 | 确认过期 | 等待超过 60 秒再确认 | 返回过期且不删除 |
| A14 | 播报打断 | 成功反馈播放时说“等一下” | 播放停止，已提交数据仍可查询 |

## 5. 生命周期与 TTS

人工矩阵还需验证：

1. 新建聊天历史后仍可查询；
2. 删除旧聊天历史不影响持久记忆；
3. 断开 Electron 并重新连接后仍可查询；
4. 正常重启后端后仍可查询；
5. 临时关闭记忆时不召回且文件不删除；
6. 重新启用后恢复读取；
7. Sherpa 完成全矩阵；
8. Fish 至少抽查保存、查询和播放中打断；
9. 字幕、语音、表情、嘴型和音频顺序正常；
10. 表情控制标签不出现在字幕或朗读中。

Fish 技术兼容性与声音资产授权继续分开记录。

- 非命令本地解析耗时；

## 7. 退出条件

M5.3.4 只有在自动化门禁和人工矩阵都通过后才能关闭。自动化完成但麦克风、TTS、
嘴型、表情或打断尚未由实际操作者确认时，状态必须保持“人工验收待完成”。
