# Elysia AI Companion M0 验收记录

## 结论

2026-08-11 完成 M0 功能与性能验收。麦克风、ASR、LLM、TTS、Live2D
嘴型与表情、播放中打断、连续对话和桌宠模式均已实际运行。

M0 当前状态为：**功能验收通过，5 秒性能门槛通过**。严格按 `turn_id`
关联的 10 次麦克风测试中，Sherpa-ONNX 本地 TTS 路径从收到句末音频到
发送首个真实音频 payload 的 p50 为 4090.7 ms；前端开始播放信号的
p50 为 4096.0 ms，均低于目标 5000 ms。10 次中有 8 次低于 5 秒，
首段音频成功率为 10/10。

MVP-A 默认使用 Sherpa-ONNX 本地通用女声，Edge TTS 保留为在线回退。
该声音仅用于验证通用语音链路，不代表最终爱莉希雅音色；角色音色留待
MVP-B 单独接入和验收。

## 性能结果

数据来自 `logs/debug_2026-08-11.log` 中的 `[PERF]` 结构化日志。最终统计
使用 `turn_id` 严格关联每一轮 ASR、LLM 首句、序号 0 的 TTS、首个非空
音频 payload 和前端播放信号。统计过程只保留阶段耗时、文本字符数和成功
状态，没有把对话、Prompt、Endpoint 或凭据写入验收记录。

早期未按 `turn_id` 严格关联的粗略统计不再作为性能结论。修正测量口径后，
先完成 Edge TTS 10 轮基线，再切换 Sherpa-ONNX，预热后完成 10 轮同口径
麦克风测试。

### Edge TTS 基线

Edge TTS 为在线服务。10 轮序号 0 的 TTS 均成功，但首个真实音频 payload
没有一次在 5 秒内发送。

| 阶段 | p50 | p90 | 最小值 | 最大值 |
|---|---:|---:|---:|---:|
| ASR | 240.4 ms | 256.7 ms | 193.3 ms | 258.0 ms |
| LLM 首句 | 2375.8 ms | 3118.4 ms | 1969.2 ms | 3140.1 ms |
| 序号 0 TTS 合成 | 2736.3 ms | 4017.8 ms | 2393.7 ms | 4313.6 ms |
| 音频 payload 构建 | 289.0 ms | 315.7 ms | 250.7 ms | 325.1 ms |
| 首个真实音频 payload | 6151.4 ms | 7010.8 ms | 5058.7 ms | 7623.2 ms |
| 前端开始播放信号 | 6173.8 ms | 7034.4 ms | 5073.8 ms | 7641.5 ms |

- 首段音频成功率：10/10。
- 首个真实音频 payload 不超过 5 秒：0/10。
- 结论：稳定性通过，延迟门槛未通过；主要耗时来自 LLM 首句和在线
  Edge TTS 串行叠加。

### Sherpa-ONNX 本地 TTS 结果

使用官方 `vits-melo-tts-zh_en` 单女声模型，CPU、4 线程、`sid: 0`。
正式测试前完成一次预热，随后记录 10 轮麦克风输入。

| 阶段 | p50 | p90 | 最小值 | 最大值 |
|---|---:|---:|---:|---:|
| ASR | 281.5 ms | 430.1 ms | 197.3 ms | 435.2 ms |
| LLM 首句 | 2403.7 ms | 3106.6 ms | 1282.2 ms | 4830.1 ms |
| 序号 0 TTS 合成 | 1166.7 ms | 1914.6 ms | 467.2 ms | 2181.1 ms |
| 音频 payload 构建 | 5.3 ms | 7.2 ms | 4.0 ms | 8.0 ms |
| 首个真实音频 payload | 4090.7 ms | 5180.6 ms | 2426.4 ms | 6184.0 ms |
| 前端开始播放信号 | 4096.0 ms | 5186.1 ms | 2434.5 ms | 6205.3 ms |

10 轮首个真实音频 payload 耗时：

```text
2573.2, 4043.1, 6184.0, 2426.4, 2664.3,
4909.3, 5069.1, 4058.5, 4276.6, 4122.8 ms
```

- 首段音频成功率：10/10。
- 首个真实音频 payload 不超过 5 秒：8/10。
- p50 相比 Edge TTS 从 6151.4 ms 降至 4090.7 ms，降低 2060.7 ms。
- 序号 0 TTS 合成 p50 从 2736.3 ms 降至 1166.7 ms。
- 6184.0 ms 的超标轮主要由 LLM 首句 4830.1 ms 导致。
- 5069.1 ms 的超标轮包含 15 字首句，本地 TTS 合成耗时 2181.1 ms。

有一轮在首段成功播放后被用户主动打断，日志中的 7 个后续 TTS
`success=False` 均为取消结果，不是合成故障；排除取消任务后，正常 TTS
分句全部成功。

最终结论：Sherpa-ONNX 路径达到 MVP-A 的“说完到首段音频开始”p50
不超过 5 秒目标。两次尾部超标分别受 LLM 首句和较长首句 TTS 影响，
不阻塞 M0；后续可以继续观测，但不再为该目标追加代码优化。

## 自动化回归

运行命令：

```powershell
$env:PYTHONPATH=(Resolve-Path .\src).Path
.\.venv\Scripts\python.exe -m pytest tests -q
```

结果：33 项测试及 7 项子测试通过，存在 1 项警告。警告为当前测试进程的
`PATH` 未解析到 FFmpeg；FFmpeg 可执行文件已独立验证，Edge 与 Sherpa
人工播放均正常。Sherpa 当前直接生成 WAV，不依赖该解码路径，因此该警告
不阻塞 M0，但后续更换压缩音频格式时需要重新确认运行进程的 `PATH`。

`pytest` 当前只安装在本地 `.venv`，尚未加入项目依赖或锁文件。
